SUMEE PARTY RENTALS WEBSITE
===========================

GitHub Pages ready:
1. Upload all files/folders from this package to the root of your GitHub repository.
2. Make sure index.html is at the repository root.
3. In GitHub: Settings > Pages > Deploy from a branch > main / root.
4. Your custom domain can be configured in GitHub Pages settings.

HOW TO SWAP EVENT GALLERY PHOTOS
--------------------------------
EASIEST METHOD (no code change):
Replace any file inside:
  assets/images/gallery/

Keep the SAME filename (example: gallery-01.jpg).
The website will automatically show the replacement picture.

To add/remove/reorder gallery pictures:
Edit:
  js/gallery-config.js

Each gallery item has:
  src: file location
  alt: short description

HOW TO SWAP RENTAL CARD PHOTOS
------------------------------
Replace files in:
  assets/images/rentals/

Keep the same names:
  tables.jpg
  chairs.jpg
  tents.jpg
  coolers-fans.jpg
  floor-mats.jpg
